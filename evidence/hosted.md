# Optional hosted generation

The workbench launches with generation disabled. Local retrieval and manual drafting require no provider credential or hosted policy. Automated generation tests inject a controlled boundary and execute the real local confirmation, cancellation, ledger and validation components. No live provider result is implied.

A separate D3 decision controls any paid experiment. The operator must first verify account access, applicable terms and rates, provider model identity, exact tokenizer, capability for strict structured output, and that the input-token count endpoint is nonbillable for the authorized account. Record dated evidence from the provider and retain the actual authorization reference. [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create) · [Input-token count endpoint](https://developers.openai.com/api/reference/resources/responses/subresources/input_tokens/methods/count)

The private mode-0600 policy has version 1.1 and the fields defined by `HostedPolicy` in `retrofit/openai_provider.py`. Use the actual D3 reference, an authorized maximum within the absolute $25 M1 experiment cap, exact model request and expected response identities, verified tokenizer, terms/rates reference and verification date, integer nanodollars per input and output token, and verified count-endpoint disposition. Provide the credential separately as `RETROFIT_OPENAI_API_KEY` in the launch environment. Keep credentials and the policy outside the source tree.

Once the operator launches with the real policy and chooses to enable authorized generation in **Local controls**, the hosted checkpoint displays the exact question and context. It explains that the requests also contain instructions and eligible public evidence excerpts. Edits require a new search and confirmation. The service independently validates session, exact input, current eligibility, enablement, authorization, count and cost ceilings before dispatch. The adapter has no tool capability, requests structured output with a hard output cap, and checks complete provider-reported input size before generation.

Canceling after dispatch prevents a late answer from replacing the canceled result. Unknown billing retains the reservation. Reconcile it against the real provider record with the versioned attempt reconciliation endpoint. Disable generation on boundary failures and retain the run and usage evidence before retrying. The applicable quality and human review gates still determine acceptance.

## Qualified author/reviewer/custodian: `evaluation-handoff.json`

Assign a qualified source-label author and a separate qualified reviewer/
custodian. Use a private account/directory inaccessible to the builder.
Prepare 90 development and 90 held-out questions, each split containing 15
direct, multi-passage, table, unanswerable, ambiguous/conflicting and adversarial
cases. Keep leakage clusters and paraphrases within their split.

Freeze corpus, exact questions/contexts, label hash/version, custody mode,
budgets, configurations and the candidate-selection rule before comparisons.
Do not put gold in app requests. Execute matched development comparisons,
select once, then run the same 90 protected cases in three distinct repetitions.
Keep failures and attempt histories in denominators. Score with private gold.
Each repetition needs recall >=0.90 overall and >=0.80 table. Precision 0.70
returned and 0.85 ranked are diagnostics, not replacement recall gates.
Keep the 200-request reference-host timing run separate. Record hardware,
versions, load, cold/warm conditions and all timing observations.

For exposure, mark SELF_EVALUATED and retire exposed held-out clusters before
claiming independence. Synthetic fixture success is not semantic quality.
Use the existing `freeze`, `run`, `select`, `report` and `billing` CLI procedures,
not a new parallel evaluator. Do not request live inference without D3/D7.

## Human accessibility tester: `human-observations.csv`

Record OS/browser/AT versions, zoom, exact keystrokes, spoken output/transcript,
focus destination and evidence per row. Automation's accessibility tree is not
screen-reader speech. Launch normally with generation disabled and a reviewed
local or supplied illustrative fixture.

1. Open native PDF picker, cancel/Escape. Focus returns; form data remains;
   no file is selected and no source is staged.
2. Keyboard search and listen for named controls, loading/result announcements.
3. Open evidence and mandatory qualifier. Confirm PDF page versus printed label,
   highlight description, dialog focus containment and Escape focus restoration.
4. Save and export a draft, including the native download interaction.
5. Repeat search/evidence/export at 200%; inspect 400% reflow.
6. Distinguish empty catalog, no evidence and disabled/unavailable provider
   without relying on color. A loopback failure is sufficient for failure-state
   observation and must not be labeled a live semantic test.
